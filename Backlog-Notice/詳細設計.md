# 詳細設計

## 1. 構成リソース・命名規則

- EventBridge Rule
  - aws-notice-rule（AWS Healthイベントのキャッチ）
- Lambda
  - aws-notice-backlog（AI要約およびBacklog API起票処理）
- IAM
  - aws-notice-slack-role
    - 権限: AmazonBedrockInvokeModel、CloudWatch Logs書き込み権限

## 2. 環境変数定義

- BACKLOG_SPACE_ID
  -  BacklogのスペースIDを.envファイルより注入
- BACKLOG_API_KEY
  -  Backlog APIキーを.envファイルより注入
- BACKLOG_PROJECT_ID
  -  起票先プロジェクトのIDを.envファイルより注入
- BACKLOG_ISSUE_TYPE_ID
  -  課題の種別IDを.envファイルより注入
- BACKLOG_USER_ID
  -  担当者（または起票者）のユーザーIDを.envファイルより注入
  
## 3. Backlog起票用本文レイアウト

Backlogへ送信する課題本文の整形仕様です。

```bash
* AWS Health通知 要約

** 概要
（Bedrockから抽出された概要）

** 緊急度
（Bedrockから抽出された緊急度）

** 対応策
（Bedrockから抽出された対応策）

* 通知原文
（EventBridgeから取得した英語の通知原文）

** 対象リソース
（影響を受けるリソースID）

** 発生リージョン
（イベントの発生リージョン）
```
