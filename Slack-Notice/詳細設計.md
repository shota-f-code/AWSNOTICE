# 詳細設計

## 1. 構成リソース・命名規則

- EventBridge Rule
  - aws-notice-rule（AWS Healthイベントのキャッチ）
- Lambda
  - aws-notice-slack（AI要約およびSlack送信処理）
- IAM
  - aws-notice-slack-role
    - 権限: AmazonBedrockInvokeModel、CloudWatch Logs書き込み権限

## 2. 環境変数定義

- SLACK_WEBHOOK_URL
  - Slack Incoming Webhook URLを.envファイルより注入（ハードコート禁止）
  
## 3. Slack通知メッセージレイアウト

Slackへ送信するブロック・テキスト構造の仕様です。

```bash
* AWS Health通知 要約
（ここにBedrockから返ってきた「*概要*」「*緊急度*」「*対応策*」の3行がそのまま入る）

* 通知原文
（EventBridgeから取得した最新のDescriptionテキスト）

** 対象リソース
（イベントの影響を受けるリソースID）

** リージョン
（イベントが発生したAWSリージョン）
```
