# 要件定義

目的： AWS Healthのイベントを自動検知し、Amazon Bedrock（AI）で要約した内容をSlackへ自動通知する。

## 機能要件

- イベント検知機能
  - AWS Healthの全イベント（障害、スケジュールされた変更、通知）をEventBridgeでリアルタイムに検知すること。
- AI要約（Amazon Bedrock）
  - イベントに含まれる英語の通知原文（Description）を読み込み、Claudeを用いて日本語で要約すること。
  - インフラエンジニアが即座に状況を判断できるよう、「概要」「緊急度」「対応策」の3項目に絞って抽出すること。
- Slackアラート自動投稿
  - 要約結果およびイベント詳細を、指定されたSlackチャンネル（Incoming Webhook）へ即座に送信すること。
  - Slackのマークダウン仕様（太字・コードブロック等）に合わせ、PC・スマホのどちらでも一目で視認できるレイアウトに整形すること。
  
## 非機能要件

- セキュリティ（認証情報の保護）
  - SlackのWebhook URL等の機密情報は、プログラムやコード上にハードコードせず、環境変数（.env / Lambda環境変数）で安全に管理すること。
- マルチリージョン連携
  - Lambdaを東京リージョン（ap-northeast-1）に配置しつつ、Bedrockの呼び出し（クロスリージョン推論等）を正常に行えること。
- 保守性・ログ管理
  - 処理の成否やエラー発生箇所（EventBridgeパース、Bedrock呼び出し、Slack送信）が追跡できるよう、適切な例外処理とCloudWatch Logsへのログ出力を実装すること。
- コスト最適化
  - 平時の維持コストを0円とし、イベント発生時のみ課金される完全従量課金構成とすること。

## 使用サービス・ツール

- AWS
  - AWS Health, Amazon EventBridge, AWS Lambda, Amazon Bedrock, IAM
- 外部サービス
  - Slack
- 開発・管理ツール
  - AWS CDK, Python, uv

## 構築アプローチ

- AWS CDK（Python）によるIaC（Infrastructure as Code）管理を実施。
